Before you begin.

Is Pokémon Relics Ultimate finished?

No. Alpha 3 is a playable testing release. Expect ongoing fixes and balance changes.

Will my old save work?

Keep a backup before switching builds. Saves may need compatibility testing after major changes.

How do I find the secret baby eggs?

Read the Odd Egg guide for all eleven passwords. The four new custom eggs are in development, not yet downloadable in Alpha 3.

Which Pokémon hatch from paid Mystery Eggs?

The upcoming ¥5,000 Day-Care egg pool contains only the nine traditional Kanto, Johto and Hoenn starters. The four PRU babies are instead obtained via secret-password Odd Eggs. Not in public Alpha 3 yet.

Where can I find Pokémon locations and evolutions?

Visit the RelicDex Pokédex and Locations guide. Records are being checked against the ROM.

How do I use the Randomizer Scanner?

In-game save first, then export the emulator's .sav file and open the save scanner. The file is processed in your browser.

Alpha 5 is likely the next public release

The current Alpha 3 download remains until Alpha 5 is verified and published. See the Legendary Guide for Alpha 5 test-ROM information.
