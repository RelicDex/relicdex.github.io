# PRU black Primal front sprites

The website uses the 64x64 native Primal form graphic with the native shiny Primal palette from the PRU source repository, not a darkened ordinary form.

Kyogre: graphics/pokemon/kyogre/primal/front.png + graphics/pokemon/kyogre/primal/shiny.pal -> assets/sprites/approved-front-updates/kyogre_primal_black.png
Groudon: graphics/pokemon/groudon/primal/front.png + graphics/pokemon/groudon/primal/shiny.pal -> assets/sprites/approved-front-updates/groudon_primal_black.png

Original indexed pixel positions were preserved; palette index 0 is transparent; indices 1-15 use the exact JASC-PAL RGB values. This only changes website front art and Legendary guide cards. No ROM changes.
